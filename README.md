# Kaspa Pong

The current application lives in [`pong/`](pong/). See its
[README](pong/README.md) for build, wallet and Host/Join instructions.

Active development is tracked on `master`, starting from a standalone
snapshot without earlier Git history. The Argent SDK is fetched from the pinned
Git revision in Cargo; a sibling checkout is not required.

Wallets, private keys, local node configuration, game records, logs and build
caches are excluded from version control. Never commit or share a funded wallet.
